# v0.9.4 Preview — archival source for the independent voice-controlled project

The files in `base64/` are **transport fragments of the original, unchanged v0.9.4 Windows ZIP**. They are *not* separate downloads. The GitHub Actions workflow reconstructs the ZIP, checks its SHA-256 and ZIP integrity, and publishes the finished artifact on **this project's own [v0.9.4 release page](https://github.com/mrslysi-creator/RAWDOGS-Voice-Controlled-Field-Calculator/releases/tag/v0.9.4-preview)**.

The release archive contains the Windows executable, Go source code, UI assets, script, README, checksums and tests. The workflow also extracts browsable source files into `src/windows/` and supporting documents into `docs/`.

**This is an optional, experimental voice-controlled calculator.** The original [Build 2.4 project](https://github.com/mrslysi-creator/RAWDOGS-Field-Calculator) remains a separate, untouched download.
