# RAWDOGS Voice Controlled Field Calculator — v0.9.4 Preview

**Experimental Windows-native preview — a separate project, not a replacement for the original Build 2.4.**

This repository is exclusively for the **RAWDOGS Voice Controlled Field Calculator**. Users may continue downloading the original [RAWDOGS Field Calculator — Build 2.4](https://github.com/mrslysi-creator/RAWDOGS-Field-Calculator) independently.

## Included
- The original Windows 64-bit `RAWDOGS_Voice_Controlled_Field_Calculator_v0.9.4_Preview.exe`.
- Complete Go source, UI graphics/icons and original test/checklist documents.
- The 87-lesson Piper guided-tour narration script.
- Compact blue/silver Walkman controls and a two-line RAWDOGS / V.C.F.C. header.
- Six-stage Actual/Target coordinate workflow and existing L81 calculations.
- Optional Buy Me a Coffee creator-support link (no compulsory donations, paid features, ads or subscriptions).

## Testing status
**Preview only: owner acceptance testing on Windows is pending.** Windows UI layout, voice recognition, device/model setup, Piper narration and text/audio synchronization require real-machine testing. Keep your known-good Build 2.4 in its own folder.
