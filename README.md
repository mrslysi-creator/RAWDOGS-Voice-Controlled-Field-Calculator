# RAWDOGS Voice Controlled Field Calculator

**Windows v0.9.4 Preview — a separate, optional calculator for the WARDOGS community.**

This repository is for the **RAWDOGS Voice Controlled Field Calculator**, developed by **sly (mrslysi-creator)** under the RAWDOGS name. It is a standalone project, **not an update or replacement for the original RAWDOGS Field Calculator Build 2.4**.

## Download & installation

**[Download v0.9.4 Preview — Windows EXE + complete Go source ZIP](https://github.com/mrslysi-creator/RAWDOGS-Voice-Controlled-Field-Calculator/releases/tag/v0.9.4-preview)**

1. Download the ZIP from this project's **Releases** page.
2. Extract it into a **new folder**, separate from any existing RAWDOGS installation.
3. Read `README_2_43_19.md` and `TEST_CHECKLIST_v0.9.4.md` in the ZIP.
4. Run `RAWDOGS_Voice_Controlled_Field_Calculator_v0.9.4_Preview.exe` on Windows.

The ZIP contains the original Windows executable, complete Go source files, images and controls, testing notes, and an indexed 87-lesson guide script. **Piper and Vosk voice/model packs are not bundled.**

## Preview capabilities

- Windows-native RAWDOGS interface with the established calculator workflow.
- Voice-assisted Actual/Target coordinate workflow and spoken firing solutions (subject to testing).
- Piper-narrated 87-lesson guide, with compact Walkman-style controls.
- Model library, device and training/diagnostic controls.
- Original calculator mathematics deliberately preserved.
- Optional [Buy Me a Coffee](https://buymeacoffee.com/silvesta) creator-support link; **no adverts, subscriptions, required donations or paid features**.

### Status / testing limitations

**Preview / experimental, not certified as a fully tested release.** The Windows layout, microphone recognition, Piper playback, model downloads and narration synchronisation still need owner testing. Keep your known-good Build 2.4 installation. Follow the included test checklist and report bugs.
